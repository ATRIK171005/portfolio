## 🌟 Highlights & Features

* **Interactive Project Showcase:** Detailed breakdowns of core architecture, algorithms, and tech stacks across cutting-edge personal projects:
  * 🚨 **VeriTruth AI (`AI_Fake_News_Detector`):** Production-grade NLP text classification platform.
  * ⚓ **VectraFlow OR (`AI_Logistics_Optimizer` / `VectraFlow`):** Capacitated Vehicle Routing Problem with Time Windows (VRPTW) solver using Google OR-Tools.
  * 🛡️ **JARVIS Suite (`Stitch_AI_Companion`):** Ultra-lightweight local neural conversational AI voice assistant optimized for `<2 GB VRAM`.
  * 🪙 **Khaata Passbook (`spendsy-app`):** Matte dark gold & black personal financial passbook and budget tracker.
  * 🪺 **NestMate (`nestmate`):** Glassmorphic campus and urban roommate housing matching platform.
* **Direct Resume & Cover Letter Access:** Includes embeddable and downloadable access to `resume.pdf` and tailored dynamic cover letter suites (`cover_letter.html`).
* **High-Performance & Zero Dependencies:** Built with pure semantic HTML5, custom CSS variables, and modern ES6 JavaScript (`script.js`) ensuring sub-second load times and flawless mobile/desktop responsiveness.
* **Smooth Micro-Animations:** Scroll-triggered element reveals, interactive floating cards, and polished contact modal interactions.

## 🚀 Quick Setup & Local Preview

To run the portfolio locally on any machine:

1. **Clone the repo:**
   ```bash
   git clone https://github.com/ATRIK171005/portfolio.git
   cd portfolio
   ```
2. **Launch a local static server:**
   ```bash
   python -m http.server 8080
   ```
3. **Open your browser:**
   ```text
   http://localhost:8080/
   ```
